# Provenance audio

## slaptax-pulse.wav

Généré par `scripts/prepare.mjs` à partir de sinusoïdes et d’enveloppes mathématiques. Aucun échantillon, enregistrement ou service de génération externe. Fond de travail original du projet, sans achat de piste effectué. Le code source est la provenance reproductible.

## cut-sweep.wav, select.wav, lock.wav, reveal.wav

Effets synthétisés localement par `scripts/decoupe-demo.mjs` : oscillateurs sinusoïdaux et enveloppes de volume, sans sample externe. Reproductibles via `npm run prepare`.
