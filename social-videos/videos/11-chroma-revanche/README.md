# 11 — Cette fois, je retrouve la couleur.

- Jeu : **chroma** ; série : Défi solo ; durée : 16 s.
- Statut : storyboard, capture réelle à fournir.
- Hypothèse : le spectateur veut essayer puis défier un ami.

## Découpage

- 0–3 s : Cette fois, je retrouve la couleur. Action visible immédiatement, sans introduction de logo.
- 3–13 s : Deuxième tentative du même joueur ; comparer sans inventer une amélioration.
- 13–16 s : résultat réel puis « Défie ton pote. Lien en bio. »

## Voix et son

J’étais sûr de moi. J’ai demandé une revanche. Voilà le résultat.

Voix française naturelle, complice, sans crier. Conserver les réactions humaines si elles apportent plus que la voix off. Musique originale locale discrète ; couper ou réduire pendant la révélation. Ajuster les durées et les sous-titres après écoute : aucun mot ne doit être tronqué.
